Download example JSON · Download JSON Schema · Download format guide

Upload a UTF-8 .json file (optional BOM), at most 256 KiB, containing schema_version: 1 and sources with 1–100 objects. Each needs name and a public HTTP(S) url. Unknown fields are rejected.

Names and companies are trimmed. URLs are not trimmed; query order is preserved. Scope defaults to the decoded starting URL path, not the whole website. Limits default to 5 pages, depth 1, delay 5 seconds and interval 168 hours; link following and external discovery are off.

Preview performs no DNS lookup or fetch and creates nothing. Confirmation creates only paused, unapproved sources with HTML / rules extraction, an empty recipe and the sales-role filter enabled. No collection, discovery or automation jobs are queued.

Public hostname resolution and robots checks happen later through the authorized collector. Import is not permission to collect.
